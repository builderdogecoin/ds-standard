# Docs

Friendly guides to the Doge Soft Standard. The normative text is [SPEC.md](../SPEC.md); if a guide and the spec ever disagree, the spec wins.

| Guide | Read it when |
|---|---|
| [verbs/marketplace.md](verbs/marketplace.md) | You run or build a marketplace |
| [verbs/social.md](verbs/social.md) | You build tips, reveals or boosts |
| [verbs/launchpad.md](verbs/launchpad.md) | You launch a collection or read royalties |
| [verbs/governance.md](verbs/governance.md) | You found an organization or tally votes |
| [verbs/security.md](verbs/security.md) | You read anchors and refunds |
| [verbs/bridge.md](verbs/bridge.md) | You read Soft Bridge inscriptions |
| [records.md](records.md) | You want to check a signed record yourself |
| [building.md](building.md) | You want to write and read tags in your own app |
| [faq.md](faq.md) | You have a question |

Full product docs live at [docs.dogesoft.io](https://docs.dogesoft.io/inscription-standard/).
